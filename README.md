# homework-10
Homework project for processing banking data


## Ядро интернет-магазина (Домашка 17)

Реализованы основные сущности e-commerce проекта с использованием ООП.

### Новые классы (src/products.py)
- **Product**: Представляет товар (название, описание, цена, количество).
- **Category**: Предвляет категорию товаров. Содержит атрибуты класса для автоматического подсчета общего количества категорий () и товаров ().
- **load_products_from_json**: Функция для загрузки данных из JSON-файла и создания объектов классов.
