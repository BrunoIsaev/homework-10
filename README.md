# homework-10

Homework project for processing banking data

## Реализованная функциональность

### Домашка 18: Инкапсуляция
- Приватные атрибуты `__products` и `__price`
- Геттеры и сеттеры с декораторами `@property`
- Класс-метод `new_product()` для создания из словаря
- Метод `add_product()` для добавления в категорию

### Домашка 19: Магические методы
- `__str__` для Product и Category
- `__add__` для сложения товаров
- `__iter__` для итерации по категории

### Домашка 20: Наследование
- Классы-наследники: `Smartphone` и `LawnGrass`
- Ограничение сложения: только объекты одинакового класса
- Ограничение добавления: только Product и его наследники

### Домашка 21: Абстрактные классы и миксины
- Абстрактный базовый класс `BaseProduct`
- Миксин `PrintMixin` для печати информации о создании объектов
- Все продукты наследуются от `BaseProduct` через `Product`

### Домашка 22: Обработка исключений
- `ValueError` при создании товара с нулевым количеством
- Метод `average_price()` в Category с обработкой деления на ноль
