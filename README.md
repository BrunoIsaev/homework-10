# Homework 10 - Banking Data Processing

Проект для обработки банковских операций клиентов с полным покрытием тестами.

## Описание

Проект включает модули для:
- Маскирования номеров банковских карт и счетов
- Фильтрации операций по статусу
- Сортировки операций по дате
- Форматирования дат

## Тестирование

### Запуск тестов

```bash
pytest
```
